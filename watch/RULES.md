# 手錶版 Pocket 規則書

給手錶韌體（另一個專案 `ESP32 S3 Watch`）用 C 重寫時照著做。規則以網頁版為準，網頁版改了數值要同步改這份。
這個資料夾的圖檔和 JSON 都是工具產生的，不要手改：

- `#watch` 頁（`npm run dev` 開 `https://localhost:5173/#watch-export` 會自動輸出）→ `sprites/<id>/full/`、`room/`、`layout.json`、`characters.json`
- `python3 tools/watch_pixel.py` → `sprites/<id>/px56/`（56 格・24 色）

## 第一版範圍（2026-10-31）

- 只有**房間養成**：數值條、餵食、清潔、睡覺／起床。
- 沒有手搖飲、節奏應援、DJ、商店、邀請作客（之後再說）。所以手錶上賺不到金幣，金幣、特殊食物、巧克力只存不顯示。
- 只放本命：本命在手錶上選定後固定（換本命＝重新開始）。
- **手錶上沒有能加心情的動作**（使用者 2026-10-31 決定先不處理）：心情照常每小時 −3，數值條要看得到它往下掉；心情 < 40 時進 Pocket 跳一次提示「{角色名} 心情不太好，\n有空用手機陪他玩吧」，提醒玩家之後用手機（小遊戲、特殊食物、巧克力）補心情，等存檔同步做好才會帶回手錶。

## 操作限制（手錶已經用掉的手勢）

- 錶面點兩下進 Pocket、短按 BOOT 回錶面：**Pocket 裡面不能用「點兩下」和 BOOT 做其他事**，只用單點按鈕。
- 5 秒沒動作會關螢幕；再亮起時回到原本的畫面，進行中的掃地動畫直接算完成。

## 數值（0～100）

| 數值 | 每小時 | 備註 |
|---|---|---|
| 飽足 `hunger` | −4 | |
| 心情 `mood` | −3 | |
| 清潔 `clean` | −4 | |
| 體力 `energy` | 醒著 0、睡覺 +50 | 睡到 100 自動起床 |

- 新本命起始全部 80。數值一律夾在 0～100，可以有小數（存檔存小數，顯示四捨五入）。
- 補算以存檔的 `lastSeen` 為唯一起點：進 Pocket、按按鈕、每隔一段時間（網頁是 5 秒，手錶可以拉長）都算「`now − lastSeen`」再把 `lastSeen` 設成 `now`，不會重複扣。
- 睡覺中補算時體力用 +50／h；補到 100 就起床，之後的時間照醒著算也可以（網頁版是整段一起算，差異可忽略）。

## 表情（照 `src/pet.ts` 的 `moodOf`）

1. 睡覺中 → `sleep`
2. 四個數值的最小值 < 15 → `sick`
3. 最小值 < 40 → `sad`
4. 其他 → `happy`

按按鈕後角色跳一下（0.4 秒，往上 16px 再落下），跳的時候一律顯示 `happy`。

## 動作

| 按鈕 | 條件 | 效果 | 提示文字 |
|---|---|---|---|
| 餵食 | 睡覺中不行；紫菜包飯 0 個不行 | 紫菜包飯 −1、飽足 +30 | 「好好吃！」；沒有時「沒有食物了」＋「每天早上 9:00 會發 3 個」 |
| 清潔 | 睡覺中不行；清潔 ≥ 70 只提示 | 掃把由左往右掃 1.5 秒，掃完清潔 = 100 | 「很乾淨，不需要清潔喔」／「洗得香香的～」 |
| 睡覺／起床 | 隨時 | 切換睡覺 | 「晚安 zZ」／「起床囉！」 |

睡覺中按餵食、清潔：提示「噓…正在睡覺」。

## 每日紫菜包飯

- 每天當地時間 9:00 發 3 個，上限 30 個；好幾天沒開也只發一次。
- 判斷：`due` = 最近一個已經過去的 9:00；`dailyFoodAt < due` 就發，並把 `dailyFoodAt` 設成 `due`。
- 發了要提示「早安！今天的 3 個紫菜包飯送到了」；滿了「早安！紫菜包飯已經有 30 個，今天的就先不發了」。

## 存檔（之後要跟手機網頁版同步）

欄位名稱、單位照網頁版 `src/state.ts` 的 `GameState`（目前版本 **8**），同步時直接對應。手錶要存的：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `version` | int | 跟網頁版共用版本號；網頁升版時手錶也要跟著看 |
| `mainId` | string | 本命 id（`characters.json`） |
| `pets[mainId].stats` | `{hunger, mood, clean, energy}` float | 0～100 |
| `pets[mainId].sleeping` | bool | |
| `food` | int | 紫菜包飯 |
| `dailyFoodAt` | int64 毫秒 | 上次發放那天 9:00 的 Unix 時間（毫秒） |
| `lastSeen` | int64 毫秒 | 上次補算的時間（毫秒） |
| `coins`、`specialFood`、`chocolate` | int | 第一版手錶不會改，原樣保留 |

新遊戲的初始值照網頁版：`food` 20、`coins` 50、`dailyFoodAt` = 最近一個 9:00、四個數值 80、醒著。

時間一律 Unix 毫秒（跟 JavaScript `Date.now()` 一樣），RTC 要先對時。

## 畫面（410×502，數字在 `layout.json`）

```
┌──────────────────────────┐
│ 飽足 ████░  心情 ████░  │  數值條 2×2（< 40 變紅）
│ 清潔 ████░  體力 ███░░  │
│   ┌──────────────────┐   │
│   │ 時鐘        窗戶 │   │  房間 64 格 × 5 倍 = 320×320
│   │      本命        │   │
│   │  垃圾  地毯  垃圾│   │
│   └──────────────────┘   │
│ [ 餵食 ] [ 清潔 ] [睡覺] │  有框線＋陰影；「睡覺／起床」是次要按鈕（淡藍底）
│  剩 12 個                │
└──────────────────────────┘
```

- 房間照網頁版畫（不用黑底；只有進 Pocket 才看得到）。圖層都是 64×64 原尺寸，整數放大 5 倍、不要平滑：
  1. `room/base.png`（牆、地板、地毯）
  2. 窗戶：`window_day`（6:00–16:59）、`window_dusk`（17:00–18:59）、`window_night`（19:00–5:59）
  3. 時鐘：`room.json` 的 `clock`（3×5 像素數字，24 小時制）。**手錶上冒號固定亮、每分鐘更新一次**，不要每秒閃（省電）。
  4. 垃圾：`room.json` 的 `trash`，清潔「低於」`below` 才出現。
  5. 本命（見下）。
  6. 掃把（只在清潔動畫時）。
- 本命：水平置中，腳底在房間第 57 格（螢幕 y = 82 + 57×5 = 367）。
  - 原畫質 `full/*.png`（300×280）縮成高 210px 顯示（要平滑）。
  - 56 格版 `px56/*.png`（60×56）每格放大 4 倍＝240×224，不要平滑；同一個角色四張共用 `palette.json` 的色盤。
  - **使用者 2026-10-31 選了原畫質**，手錶用 `full/`。`px56/` 留著當參考，手錶不用轉。
- 文字置中；稱呼角色用「他／他們」，數量用「個」。

## 動畫與省電

- 平常整個畫面**靜止**：不呼吸、不眨眼、睡覺的 Z 已經畫在 `sleep.png` 裡（不飄）。
- 只有按按鈕時播一次：跳一下 0.4 秒、掃地 1.5 秒（`room.json` 的 `broom`），播完就停止重畫。
- 數值條只在補算後數值有變時重畫。
