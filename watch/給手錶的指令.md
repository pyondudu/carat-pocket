# 給手錶那邊 Claude 的指令

燒錄由手錶專案（`~/桌面/Claude/ESP32 S3 Watch/`）的 Claude 做，不用請他來這個資料夾。
兩個專案在同一台電腦，他直接讀這裡的 `watch/` 就好。

## 第一次：把 Pocket 放進手錶

把下面整段貼給手錶那邊的 Claude（先把 `<本命 id>` 換掉，id 查 `characters.json`，例如 TAMTAM 是 `tamtam`）：

```
Carat Pocket 的手錶版素材準備好了，請從 ~/桌面/Claude/Carat Pocket/watch/ 讀：
- RULES.md：Pocket 第一版的規則書（只做房間養成：數值、餵紫菜包飯、清潔、睡覺／起床），照這份用 C 實作
- sprites/<本命 id>/full/{happy,sad,sick,sleep}.png：本命四個表情（原畫質 300×280，已決定用這版，px56/ 不用）
- room/：房間圖層與 room.json（64 格，放大 5 倍）
- layout.json：410×502 畫面的版面數字與顏色
- characters.json：角色 id 與名字
本命是 <本命 id>，手錶只放這一個角色。
請把 CLAUDE.md 第 31 行「從 public/sprites/ 讀」改成讀 watch/。
Pocket 裡不用點兩下和 BOOT；平常畫面靜止，只有按按鈕時播一次動畫。
寫好轉檔腳本（PNG → LVGL 圖檔）後轉檔、編譯，再燒進手錶。
```

## 之後改了角色圖、表情、房間或規則

1. 在這個專案（Carat Pocket）請這邊的 Claude 重新輸出：
   - 角色圖、表情、房間：`npm run dev` 開 `#watch-export` 自動輸出到 `watch/`（56 格參考版另跑 `python3 tools/watch_pixel.py`）。
   - 規則或數值：改 `watch/RULES.md`。
2. 到手錶專案貼這段：

```
Carat Pocket 的 watch/ 更新了（改了：＿＿＿＿），請重新轉檔、照 RULES.md 調整程式，再燒進手錶。
```
